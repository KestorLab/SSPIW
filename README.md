Это библиотека была создана джуниром для джуниоров что бы каждый раз не писать огромное количество кода и терять драгоценное время. ПРИМЕР КОДА

Сохранение json: SSPIW005.Save("(название файла или переменная как хотите).json", yourdata, "(путь ИЗ папки с проэктом типо Папка_проэкта/ваша папка/папка и т.д (папки создаются автоматически) )" переваривает все типы данных ведь дата работает через обьекты Загрузка json Работает через обьекты тоже Загрузка ЧИСЛА: int (имя переменной) = SSPIW005.Load<int>("(имя файла для загрузки).json"); Загрузка СТРОКИ: string (имя переменной) = SSPIW005.Load<string>("(имя файла для загрузки).json"); вид данных надо записывать в <> и т.д КОДЫ ОШИБОК(их надо записывать в переменные при вызове) 0 - Всё прошло успешно 1 - Ошибка сохранения 2 - Ошибка передачи данных(проблема путей) SaveNeW - тоже самое, но сохраняет ошибки в лист last_errors_code, параметр error write принимает true или false LoadNeW - тоже самое, но сохраняет ошибки в лист last_errors_code, параметр error write принимает true или false
